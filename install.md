# Алгебра LAB 0.9.0 — Raspberry Pi 3 Model B+

Нативное приложение для экрана 1024×600. После установки работает без интернета. Системные зависимости: Raspberry Pi OS Buster или новее, Python 3.7+, python3-tk и графический рабочий стол. Для одного RC522 нужны python3-spidev и python3-rpi.gpio. Python/Tk и библиотеки GPIO не входят в небольшой .deb.

## Установить или обновить

Закройте старое окно приложения. Перенесите установщик через флешку. Откройте терминал в папке с файлом и выполните:

```bash
sudo apt install ./algebra-lab_0.9.0_all.deb
```

Если библиотеки RC522 ещё не установлены:

```bash
sudo apt install python3-spidev python3-rpi.gpio
```

Для загрузки отсутствующих зависимостей нужен интернет или заранее подготовленные системные пакеты. После установки приложение работает офлайн. Запускайте из меню приложений от обычного пользователя, без sudo. В заголовке окна должно быть «Алгебра LAB 0.9.0».

## Как ребёнок проходит урок

**1. Первый урок — показ.** При x+1=2 приложение выбирает «Убрать +1» и первую чашу. Ребёнок подносит +1, убирает метку на две секунды и повторяет действие на второй чаше. Это единственный начальный показ с автоматическим выбором стороны.

**2. Со второго урока — выбор ребёнка.** Нужно самому нажать **Убрать / Добавить**, затем выбрать левую или правую чашу и поднести **+1 либо +2**. Метка означает величину блока, кнопка — действие. После первого изменения следующая чаша не выбирается автоматически: ребёнок должен сам указать, где повторить то же действие. Считыватель один; выбранную сторону показывает экран.

**3. С третьего урока — самостоятельная задача.** Цель — освободить x, сохраняя равенство. Можно использовать +2 вместо двух пар действий с +1. Неверный с точки зрения цели, но равносильный ход не объявляется ошибкой: например, можно добавить единицы к обеим сторонам, увидеть, что их стало больше, и отменить. Нельзя убрать больше положительных единиц, чем имеется на чаше. При незавершённой паре нужно повторить ту же величину на другой стороне либо нажать **Отменить**.

**4. Ответ выбирает ребёнок.** После освобождения x игра ещё не завершена. Нужно показать число меткой **+1 / +2** либо выбрать число из предложенных ответов на экране и нажать **Проверить**. Метка **x** подтверждает уже выбранное на экране число. Проверка выполняется подстановкой в исходное уравнение. Неправильный ответ не даёт XP и не открывает следующий урок; ребёнок видит объяснение. Награда появляется только после правильного ответа.

Пример для x+2=3: **Убрать → левая чаша → метка +2 → правая чаша → метка +2**. Затем ребёнок показывает ответ **+1**. Использование метки +1 дважды на каждой чаше — другой допустимый путь через две пары.

Метка x не предназначена для убирания единиц на начальных чашах; её роль в этом режиме — подтвердить выбранный окончательный ответ. Поэтому вместо безымянного «другая метка» сообщение объясняет нужную величину или ещё не сделанный выбор.

**Подсказка** показывает совет по запросу и учитывается при начислении звёзд. **Отменить** сбрасывает незавершённую пару либо отменяет законченный ход. При закрытии сохраняется последнее подтверждённое уравнение, включая ожидание ответа; половина пары не сохраняется и не применяется повторно.

Первая глава: x+1=2, x+1=3, x+2=3, x+2=4, x−1=1, x+3=5. Метки и результаты предыдущих версий сохраняются. Диагностика, результаты, дополнительные 24 задания и настройки остаются в **Для взрослого**. Полный интерфейс можно вернуть переключателем **Простой детский экран**. Раздел для взрослого не защищён паролем.

## Дисплей и крупный текст

Рабочее поле растягивается по высоте окна: после сокращения служебных панелей весы занимают освободившееся место снизу. В детском режиме крупнее текст заданий, подписи, блоки и кнопки. Вместе с пакетом поставляется округлый шрифт **Algebra Rounded** с кириллицей — статические начертания на основе Nunito под SIL OFL; загрузка через интернет не требуется, лицензия включена. При недоступности шрифта используется системный.

Запуск по умолчанию полноэкранный, чтобы не оставлять снизу рабочий стол и панели ОС. F11 переключает режим, Esc выводит из полного экрана. Без клавиатуры: **Для взрослого → Настройки приложения → Оконный / полноэкранный режим**. Выбор взрослого сохраняется. Для явного запуска в окне: `algebra-lab --windowed`. В настройках также показаны фактические разрешение экрана и размер окна — если свободная полоса остаётся, сравните эти значения.

## Весы, опыт и карта уроков

Коромысло, цепочки, подставка и чаши нарисованы средствами Tk Canvas. Синий x — неизвестное число, жёлтый +1 — единица, красноватый −1 — отрицательная единица. Левая чаша голубая, правая коралловая; выбранная сторона выделена фиолетовым и подписана. Можно нажать саму чашу или её большую кнопку над рисунком.

После изменения одной стороны коромысло плавно наклоняется к большей математической величине; после одинакового действия на другой стороне выравнивается. Это схема уравнения: значения определены математической моделью, датчиков массы нет. Количество нарисованных блоков не используется как масса x. Анимация длится восемь кадров примерно по 32 мс; она конечная и отключается в настройках взрослого переключателем анимации.

XP вычисляются по лучшим звёздам известных заданий: одна звезда — 10 XP, за лучший результат 3 звезды — 30 XP. Каждые 60 XP открывают следующий игровой уровень. Повтор того же результата сохраняет занятие в статистике, но не увеличивает XP; улучшение лучшего результата добавляет разницу. Ранее полученные звёзды учитываются автоматически. На экране успеха показывается прибавка опыта и новый уровень, если он достигнут.

**Карта приключения — 24 уровня в четырёх главах:**

1. **Первые открытия:** прежние шесть уроков, от показа к самостоятельным действиям.
2. **Числа побольше:** больше единиц, отрицательные слагаемые и план из нескольких шагов.
3. **Зеркальные весы:** неизвестное справа — правило равновесия остаётся тем же.
4. **X с двух сторон:** сначала убрать одинаковые блоки x с обеих чаш, затем работать с единицами.

Первый показ открывается сразу. После него можно выбирать любой урок первой главы. Следующая глава открывается после всех шести уровней предыдущей. Внутри открытой главы порядок свободный; пройденные уровни доступны для повторения. Старые результаты первых шести уроков учитываются автоматически. Кнопка следующего задания выбирает доступный непройденный уровень.

В четвёртой главе **Убрать → чаша → метка x** убирает один блок x; то же действие нужно повторить на второй чаше. Числовые метки +1/+2 работают как раньше. Если ответ больше двух, выберите число на экране и нажмите «Проверить» либо поднесите x для подтверждения. Новых меток не требуется.

**Четыре квиза по три вопроса** доступны кнопкой «Квиз главы» после её шести математических уровней. Ответ выбирается касанием, RFID в квизе не меняет задачу. Ошибка сопровождается объяснением и позволяет попробовать снова; правильный ответ открывает кнопку «Дальше». После третьего вопроса результат попадает в статистику: три звезды без ошибок, две с одной ошибкой, одна с двумя или более. XP учитывают лучший результат, поэтому повторы без улучшения не добавляют опыт. Незаконченный квиз при повторном открытии начинается сначала; математическая сессия сохраняется отдельно.

«Мои открытия» показывает уровень, XP, число решённых заданий и попыток, а также время занятий. Дополнительные 24 задания и подробная статистика доступны взрослому. Отдельного редактора примеров в 0.9.0 нет. Новые уровни и квизы не требуют дополнительных библиотек и работают без интернета.

Дополнительных тяжёлых библиотек или загружаемых изображений нет. Canvas использует ограниченное число векторных объектов, а во время анимации перемещает существующие элементы. XP и статистика пересчитываются при действиях, а не на каждом кадре. Производительность конкретной Raspberry Pi всё равно нужно оценить на устройстве.

## Узнать номер метки на Android

1. Включите NFC в настройках Android.
2. Откройте **NFC Tools**, вкладку **Прочитать**, либо **NXP TagInfo**.
3. Приложите одну метку к области NFC на задней стороне телефона.
4. Скопируйте **UID / серийный номер в HEX** — например `12:34:56:78`. Это пример формата, не готовый номер вашей метки. Не копируйте текст, ссылку или NDEF-содержимое, записанные внутри метки.

Не каждый телефон поддерживает все типы меток. RC522 работает с ISO14443A; сам факт наличия NFC не означает совместимость любого типа с RC522. Если приложение показывает тип метки, сохраните его вместе с UID. Ничего записывать на метку телефоном не требуется.

## Подготовить назначения без считывания RC522

Откройте **Для взрослого → Мои метки**.

Для одной метки: **Добавить номер с телефона** → вставить UID → выбрать значение → **Сохранить назначение**. Для первых уроков выберите **+1**. Дописывать или удалять байты вручную не нужно: программа преобразует номер сама. Перед сохранением видно новое значение и прежнее, если оно меняется.

Для готового списка: **Загрузить список с флешки** → выбрать TXT, CSV или JSON → проверить назначения → **Сохранить этот список**. До подтверждения база не меняется. Импорт добавляет и обновляет только перечисленные номера, сохраняя остальные метки и учебный прогресс. Если назначение метки сейчас используется в свободной лаборатории, изменение отклоняется до её удаления с чаши. Ошибка в файле или при записи не должна оставлять частично импортированный список.

Простейший файл UTF-8, одна метка в строке:

```text
UID;значение
12:34:56:78;+1
AA:BB:CC:DD;x
```

Оба номера выше вымышлены. Сначала получите настоящие номера. Разрешены x, −x, 1, −1, 2, −2, 5; для дополнительных режимов также имена команд add, subtract, multiply, divide, apply, undo, hint, next, clear, guide.

Телефонный UID должен содержать 4, 7 или 10 байт HEX; пробелы, двоеточия и дефисы допускаются. Порядок байтов сохраняется. Для четырёхбайтных меток программа формирует прежний идентификатор драйвера с BCC; для длинных — прежний числовой UID. Два разных значения одного номера в списке считаются ошибкой. Лимиты: 128 КБ, до 1000 назначений.

**Сохранить копию назначений** создаёт JSON для резервной копии и переноса на другой Raspberry Pi. Его можно импортировать обратно той же кнопкой. В экспортированном файле указан `format: reader`, чтобы не преобразовать номера повторно; не меняйте этот маркер. Обычные JSON со списком UID → значение по умолчанию считаются номерами с телефона.

Загрузка UID упрощает назначение ролей, но во время игры RC522 всё равно должен прочитать метку. Она не устраняет физические ошибки обмена или питания. Привязка в приложении не записывает данные в память метки.

## Если RC522 не читает

**Для взрослого → Проверка считывателя** показывает последний технический код и позволяет переподключить модуль. Серия ошибок видна на детском экране понятным сообщением; подробности предназначены взрослому. SPI включается штатно через raspi-config → Interface Options → SPI. Первый модуль: SPI0 CE0, /dev/spidev0.0, RST BCM25. Для доступа без root нужны группы spi и gpio; после изменения групп требуется повторный вход в систему.

Подключение: питание 3,3 В → физ.1; GND → физ.6; RST → физ.22; MISO → физ.21; MOSI → физ.19; SCK → физ.23; SDA/SS → физ.24. SDA здесь — выбор SPI-устройства. IRQ не используется. Второй считыватель в этой версии не опрашивается, масса не измеряется.

Опрос раз в 0,8 с; после RF-ошибок пауза растёт до 2 с. Принимается первый полный UID с проверенной длиной и BCC. Удержание не повторяет действие: для перевзвода нужны два чистых подтверждения отсутствия, разнесённых не менее чем на 0,7 с. Для обычных меток антенна не перезапускается перед каждым опросом. Режим чтения из 0.5.0 сохранён. Физическую устойчивость ещё необходимо проверить на устройстве пользователя; ранее отмеченный Low Voltage нельзя считать устранённым.

## Данные и совместимость

База: ~/.local/share/algebra-lab/algebra.sqlite3 либо каталог XDG_DATA_HOME/algebra-lab. Обновление сохраняет метки и результаты. Перед резервным копированием всей базы закройте приложение. Применённые шаги практики сохраняются; неполная пара действий с чашами и ещё не применённый набор выражения после перезапуска очищаются.

Пакет Architecture: all, без встроенного браузера и тяжёлых Python-зависимостей. Объём установки с системными библиотеками зависит от уже установленного ПО; apt показывает его до подтверждения. На конкретной Raspberry Pi пользователя эта сборка ещё не проверена. Старые JSON-сохранения сторонней PyQt-версии автоматически не импортируются: их формат неизвестен.

Сборка: `python3 scripts/build_deb.py`. Проверка: `DISPLAY=:97 /usr/bin/python3 -m unittest discover -s tests -v` при наличии Tk и X11/Xvfb. Удаление: `sudo apt remove algebra-lab`; домашняя база сохраняется.
