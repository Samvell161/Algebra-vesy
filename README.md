# Алгебра LAB 0.3.1 — простая привязка RFID-меток

Скачайте algebra-lab_0.3.1_all.deb и перенесите на Raspberry Pi.
Закройте прежнюю версию приложения. Откройте терминал в папке с установщиком:

    sudo apt install ./algebra-lab_0.3.1_all.deb python3-spidev python3-rpi.gpio

Для загрузки отсутствующих системных библиотек нужен интернет. После установки
приложение работает офлайн. Не запускайте само приложение через sudo.
Обновление сохраняет привязки и учебный прогресс версии 0.3.0.

Запустите «Алгебра LAB» из меню приложений:

1. Настройки → RFID-метки → Считать метку.
2. Уберите метку от антенны и поднесите снова. Дождитесь «Метка считана».
3. Выберите x, 1, 2, −x, −1, −2 (также доступно 5).
4. Нажмите «Сохранить привязку», дождитесь «Сохранено».
5. Закройте окно, откройте лабораторию, выберите чашу и снова поднесите метку.

Считанный UID фиксируется до следующего нажатия «Считать метку».
Кнопка «Мои метки» показывает сохранённые назначения, изменение и удаление.
Если метка уже зарегистрирована на чаше, сначала удалите её с чаши для смены значения.
Одна метка имеет одно назначение. Режим RC522 запоминается для запуска из меню.
Неизвестная метка в лаборатории автоматически открывает окно привязки.
Для экранных блоков без оборудования есть кнопка в настройках.

Поддерживается один RC522: SPI0 CE0 (/dev/spidev0.0), RST BCM25.
SPI включается через raspi-config → Interface Options → SPI.
При ошибке доступа проверьте группы spi и gpio (подробности в инструкции).
Ошибки подключения теперь показываются в самом окне привязки.

Полная инструкция: Установка-и-RFID.md
Проверены 72 автоматических теста и работа извлечённого пакета в Linux/X11.
Физический RC522 и Raspberry Pi пользователя в этих проверках не участвовали.
