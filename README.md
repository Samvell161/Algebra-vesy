# Алгебра LAB 0.4.0 — решение уравнений RFID-метками

Закройте старую версию. Скачайте .deb, перенесите на Raspberry Pi и в папке с ним выполните:

    sudo apt install ./algebra-lab_0.4.0_all.deb

Запустите «Алгебра LAB» из меню обычным пользователем. Прежние привязки и прогресс сохраняются.
Если системных библиотек RC522 ещё нет, их установка (с интернетом):

    sudo apt install python3-spidev python3-rpi.gpio

Для вашего комплекта с одной уже привязанной меткой:

1. На главной нажмите «Решать физическими метками».
2. Выберите «Одна метка · обучение» (это режим по умолчанию).
3. Прочитайте показанное действие и поднесите вашу метку примерно на секунду.
4. Уравнение изменится. Для следующего шага уберите метку на две секунды и поднесите снова.
5. После решения ещё одно поднесение открывает следующий пример.

Здесь любая привязанная метка — пульт, подтверждающий предложенный учебный шаг.
Её числовое назначение в этом режиме не является операндом. Это обучение с подсказками;
помощь учитывается при начислении звёзд. Можно пройти все 24 задания без ввода ответа.

Для самостоятельного решения выберите «Набор меток · свои действия».
Назначьте меткам числа/x и команды через «Мои метки → Считать метку → Числа и x / Команды».
Числовые метки собирают выражение, команды выбирают действие, а «Применить»
выполняет его с обеими частями. Например, для x + 3 = 7:

    Вычесть → 2 → 1 → Применить  =  x = 4

Вместо 2 и 1 можно трижды предъявить одну метку 1 с удалением из зоны между предъявлениями.
Поддерживаются команды четырёх действий, применение, очистка набора, отмена, подсказка,
следующее задание и явный шаг с подсказкой. В физическом экране нет ручного ввода ответа.
Для самостоятельного выбора разных значений/команд нужны отдельные метки.

Первое предъявление на главной открывает условие, не решает его: уберите и поднесите метку снова.
Открытое окно привязки захватывает UID, но не выполняет математическое действие.
История применённых шагов сохраняется; незавершённый набор операнда после перезапуска очищается.
Свободная лаборатория остаётся отдельным реестром блоков на чашах; для заданий используйте
кнопку «Решать физическими метками», также доступную из лаборатории.

Используется один RC522: SPI0 CE0 (/dev/spidev0.0), RST BCM25. Второй модуль не нужен.
Сохранены опрос 350 мс, подтверждение UID двумя чтениями и восстановление после RF-ошибок.
Все 24 задания проверены обоими физическими сценариями в модели; всего 100 автоматических
проверок и запуск извлечённого установщика. Работа настоящего RC522 на устройстве пользователя
ещё требует проверки. Системные библиотеки не включены в .deb; после установки приложение офлайн.
Полная инструкция — Установка-и-RFID.md.
