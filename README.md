# Алгебра LAB 0.7.0 — цветные весы и небольшое приключение

Закройте прежнее окно приложения. Скачайте .deb и в папке с ним выполните:

    sudo apt install ./algebra-lab_0.7.0_all.deb

Запустите из меню. В заголовке должно быть «Алгебра LAB 0.7.0».
Назначения меток и учебные результаты сохраняются. Если вы уже загрузили свои метки в 0.6.0,
повторный импорт не требуется. В ZIP оставлена копия my-tags.json для новой установки:
«Для взрослого → Мои метки → Загрузить список с флешки → my-tags.json → Сохранить».

Что нового:

- Настоящий векторный рисунок весов: подставка, коромысло, цепочки и две чаши.
- Голубая левая чаша, коралловая правая; синие x, жёлтые +1 и фиолетовые акценты.
- Короткая анимация: после действия на одной стороне весы наклоняются;
  после такого же действия на другой стороне возвращаются в равновесие.
- Чашу можно выбрать касанием рисунка или большой кнопки над ней.
- Небольшой уровень, XP и полоска опыта на главной. Победа показывает новые XP.
- Карта шести первых уроков с последовательным открытием и повторением пройденных.
- «Мои открытия»: уровень, XP, число уроков, попыток и время занятий.

Повторять уроки можно сколько угодно. XP начисляются по лучшим звёздам известных заданий:
звезда = 10 XP, новый уровень каждые 60 XP. Повтор того же результата не увеличивает XP,
улучшение результата добавляет разницу. Старые результаты учитываются автоматически.
Редактора своих примеров нет, как и согласовано; дополнительные задания доступны взрослому.

Для первых уроков используйте метку +1. Выбранная чаша подсвечена. Поднесите метку,
уберите на две секунды и поднесите снова для другой стороны. Весы — математическая схема,
а не датчик массы. Весь эффект наклона определяется уравнением; x не считается просто одним грузиком.

Анимация конечная: восемь кадров по 32 мс, без бесконечного фонового эффекта.
Можно отключить её через «Для взрослого → Настройки приложения → Анимация весов».
Графика только Tk Canvas, внешних графических библиотек, видео и загрузки изображений нет.
Драйвер RC522, опрос и импорт UID не изменены относительно 0.6.0 (сравнены побайтово).

Проверены 143 автоматических проверки и работа извлечённого установщика, включая
направление наклона, завершение/отмену анимации, постоянное число объектов Canvas,
начисление XP, защиту от повторного начисления и открытие карты.
Пиковая память в облачной Linux x86_64/X11 проверке — около 33 МБ, без X-сервера и ОС.
Это не замер Raspberry Pi: фактическую плавность на вашем устройстве нужно проверить отдельно.
Приложение использует системные Python/Tk и GPIO-библиотеки; после установки работает офлайн.

Полная инструкция: Установка-и-RFID.md. Рядом доступны снимки новых весов и карты.
