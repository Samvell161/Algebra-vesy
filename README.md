# Алгебра LAB 0.8.0 — ребёнок выбирает и отвечает сам

Закройте старое приложение, скачайте .deb и в папке с ним выполните:

    sudo apt install ./algebra-lab_0.8.0_all.deb

Откройте из меню. Метки, пройденные уроки и XP сохраняются, повторный импорт не нужен.
Для новой установки в комплекте оставлен my-tags.json с прежними назначениями +1, +2, x.
Импорт: «Для взрослого → Мои метки → Загрузить список с флешки».

Как изменились уроки:

1. Первый урок показывает правило: убираем по +1 с каждой чаши.
2. Со второго ребёнок сам выбирает добавить/убрать, нужную чашу и числовую метку +1 или +2.
   После первого действия следующая чаша автоматически не выбирается.
3. С третьего урока предлагается цель «освободи x»; готовое преобразование не подставляется.
   Разрешены равносильные, но не приближающие к цели ходы: их можно исследовать и отменять.
4. Когда x выделен, это ещё не победа: ребёнок сам показывает ответ меткой +1/+2
   или выбирает число на экране и нажимает «Проверить». Меткой x можно подтвердить выбранное число.
5. Проверка использует исходное уравнение. Только верный ответ завершает урок и даёт XP.

Пример x+2=3:

    Убрать → левая чаша → метка +2 → правая чаша → метка +2 → ответ меткой +1.

Числовая метка означает величину, а добавить или убрать выбирается кнопкой.
Нельзя убрать больше единиц, чем имеется на чаше. Если запутался, можно отменить ход
или запросить подсказку. Подсказка учитывается в результате. Между предъявлениями
убирайте метку примерно на две секунды. Считыватель один, сторону определяет экран.

Экран:

- Более крупные блоки, кнопки, инструкции и ответы.
- Новый округлый шрифт с кириллицей (входит в пакет, загрузка из интернета не нужна).
- Меньше служебных отступов, рабочая область и весы растягиваются по высоте окна.
- Полноэкранный запуск по умолчанию, чтобы не оставлять снизу рабочий стол и панели ОС.
- F11/Esc переключают режим. Без клавиатуры: «Для взрослого → Настройки приложения →
  Оконный / полноэкранный режим». Выбор взрослого сохраняется. CLI: algebra-lab --windowed.

Если свободная полоса всё ещё остаётся, в настройках показаны фактические разрешение
экрана и размер окна. Название программы с версией видно в заголовке оконного режима;
версия также указана в диагностике считывателя.

Новый шрифт Algebra Rounded — статическая производная Nunito с кириллицей/латиницей,
поставляется с SIL OFL 1.1. fontTools на Raspberry Pi не нужен. Весы остаются лёгкой графикой
Tk Canvas с конечной анимацией, без внешних графических библиотек и бесконечных эффектов.
Полная инструкция и лицензия шрифта включены в установленный пакет.

Проверены 154 автоматических проверки, включая все шесть уроков с выбором ученика,
отсутствие награды до правильного ответа, сохранение стадии ответа после перезапуска,
работу метки +2, подтверждение меткой x, геометрию всех фаз 1024×600 и запуск .deb.
Извлечённый пакет проверен с новым шрифтом. Облачный Linux x86_64/X11 не заменяет
проверку физической Raspberry Pi и её дисплея. Чтение RC522 и конверсия UID сохранены
без изменений относительно 0.7.0.
