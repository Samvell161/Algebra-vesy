# Алгебра LAB 0.5.0 — понятные первые уроки с чашами

Закройте прежнее окно, скачайте .deb и установите из папки с файлом:

    sudo apt install ./algebra-lab_0.5.0_all.deb

Откройте приложение из меню. В заголовке должно быть «Алгебра LAB 0.5.0».
Прежние назначения меток и прогресс сохраняются. На главной нажмите
«Решать физическими метками»: откроются первые шесть простых уроков.

Сейчас достаточно одного считывателя и одной метки +1. Если метка означает x,
поднесите её, нажмите «Моя метка — +1» и подтвердите «Сохранить привязку».
Никакой скрытой перепривязки нет: изменение подтверждает пользователь.

Первый пример: x + 1 = 2.
Слева показан синий x и жёлтая единица. Справа — две жёлтых единицы.

1. Левая чаша подсвечена. Поднесите +1: исчезнет только левая единица.
2. Правая чаша подсветится. Уберите метку на 2 секунды и поднесите снова.
3. Теперь единица исчезнет справа: получится x = 1. Только тогда шаг завершён.
4. Ещё одно поднесение после удаления метки откроет следующий урок.

Можно первым касанием выбрать правую чашу: второе действие будет слева.
Считыватель один, он сам не различает стороны. Сторону задаёт экран.
Режим «Убрать блок» означает вычесть значение метки с выбранной стороны;
«Добавить блок» — прибавить. Отмена сбрасывает незаконченный шаг или отменяет
последнюю подтверждённую пару действий. Половина пары после закрытия не сохраняется.

Примеры идут постепенно: x+1=2, x+1=3, x+2=3, x+2=4, x−1=1, x+3=5.
В первых примерах убираем по единице; в пятом добавляем +1, погашая −1.
Для каждой пары используется та же физическая метка +1 после удаления из зоны.
После шести уроков кнопка «Дальше» открывает исходные 24 более сложных задания.
Они и дополнительные режимы обучения/команд сохранены.

Чтение:
- Нормальный опрос раз в 0,8 секунды, после RF-ошибок пауза растёт до 2 секунд.
- Для обычной метки нет перезапуска антенны перед каждой попыткой.
- Первого полного UID с проверенными длиной и BCC достаточно: не нужны два удачных чтения подряд.
- Ошибки не отменяют уже прочитанный UID и не вызывают повторных действий.
- Два чистых ответа «метки нет» подтверждают удаление; удобно убирать метку на 2 секунды.
- Серия ошибок видна понятным предупреждением. Полный последний код, даже если он уже прошёл,
  доступен взрослому через «Проверка считывателя»; там есть переподключение.

Работает один RC522, SPI0 CE0 / RST BCM25. Требуются установленные Python/Tk,
python3-spidev и python3-rpi.gpio; после установки приложение работает офлайн.

Проверки: 121 автоматическая проверка, запуск извлечённого установщика,
проверки отдельных чаш и парного изменения, курс из шести заданий, геометрия 1024×600.
Качество реального чтения и питание нужно проверить на Raspberry Pi пользователя.
Программные тесты не доказывают устранение физической неисправности RC522.

Полная инструкция: Установка-и-RFID.md. Снимки экранов рядом с установщиком.
