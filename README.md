# Алгебра LAB 0.6.0 — простой экран и готовые метки

В комплекте установщик и my-tags.json с тремя назначениями, указанными пользователем:

    1D:91:CE:96:68:00:00 → +1
    04:3B:C2:B7:CE:2A:81 → +2
    04:6E:BB:B7:CE:2A:81 → x

Распакуйте архив, перенесите папку на Raspberry Pi и закройте прежнее приложение.
Откройте терминал в распакованной папке:

    sudo apt install ./algebra-lab_0.6.0_all.deb

Запустите приложение из меню обычным пользователем. Заголовок: «Алгебра LAB 0.6.0».
Откройте «Для взрослого → Мои метки → Загрузить список с флешки».
Выберите файл my-tags.json из комплекта и подтвердите «Сохранить этот список».
После подтверждения все три назначения готовы; считывать их заново для привязки не нужно.
Старые назначения вне файла и учебный прогресс сохраняются. Изменяемые назначения видны до сохранения.

Для первых шести уроков используйте первую метку (+1). Можно подписать метки +1, +2, x.
Нажмите «Начать занятие». На детском экране остаются две чаши и отмена;
шаг определяется простым уроком. Главы, XP, задание дня, команды и технические настройки
с основного экрана убраны. Результаты и дополнительные возможности доступны взрослому.

Пример x+1=2: поднесите +1 к считывателю — единица исчезнет слева.
Правая чаша подсветится; уберите метку на 2 секунды и поднесите снова.
Единица исчезнет справа, получится x=1. Для следующего урока снова уберите и поднесите метку.
Считыватель один: выбранную сторону показывает экран.

Все три номера из телефона — семибайтные. Файл помечен format=phone, приложение
само преобразует UID в представление драйвера без ручного изменения байтов.
При добавлении новых меток на Android можно использовать NFC Tools → Прочитать → UID/серийный номер
либо NXP TagInfo. Нужно копировать UID в HEX, а не записанный внутри текст/ссылку.

Предварительная загрузка готовит назначения. Во время игры RC522 всё равно должен читать UID;
файл не устраняет ошибки питания, проводки или протокола. Чтение из 0.5.0 не изменено:
интервал 0,8 с, увеличенные паузы после RF-ошибок, один полный проверенный UID на предъявление.
Диагностика: «Для взрослого → Проверка считывателя». После установки приложение работает офлайн.
Для RC522 нужны установленные python3-spidev и python3-rpi.gpio; в .deb они не включены.

Проверки: 137 автоматических проверок, запуск извлечённого установщика,
импорт с предварительным просмотром, откат при ошибке SQLite, сохранность прогресса,
соответствие UID телефона идентификаторам драйвера, экран 1024×600.
Дополнительно проверено программное соответствие всех трёх номеров каскадному чтению UID.
Физическое качество чтения на Raspberry Pi пользователя ещё требует проверки.
