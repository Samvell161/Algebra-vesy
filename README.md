# Алгебра LAB 0.4.1 — совместимый профиль чтения RC522

Закройте прежнее окно приложения. Скачайте .deb и в папке с ним выполните:

    sudo apt install ./algebra-lab_0.4.1_all.deb

Запустите приложение из меню обычным пользователем. В заголовке должно быть
«Алгебра LAB 0.4.1». Назначения меток, прогресс и функции физического решения 0.4.0 сохраняются.
Для проверки откройте Настройки → RFID-метки → Считать метку.

ErrorReg=0x01 означает ProtocolErr — ошибку протокола. Она не доказывает наличие
нескольких меток или слишком высокую частоту опроса. Точную причину на конкретном
устройстве нельзя установить без проверки этапа обмена и фактического оборудования.

В 0.4.1 для обычной четырёхбайтной метки используется минимальный UID-only путь
REQA → ANTICOLLISION без SELECT/SAK/HALT, как у SimpleMFRC522.read_id_no_block.
Длинные UID сохраняют каскадную обработку. Восстановлено стандартное усиление
приёмника (33 дБ с сохранением резервных битов), явно заданы режимы ISO14443A.
StartSend сбрасывается до чтения результатов. Таймер с ProtocolErr не считается снятием метки.
Перед пробным чтением поле перезапускается, а логическая защита от повторов сохраняется.
UID/BCC преобразуется в прежний идентификатор, так что перепривязка не нужна.

Ошибки содержат этап, ErrorReg и VersionReg, когда доступны, например:

    REQA: запрос метки: ProtocolErr (ErrorReg=0x01). VersionReg=0x92.

Если ошибка осталась, сохраните весь новый текст: REQA означает запрос,
UID CL1 — первый этап чтения UID, SELECT — каскадный выбор для длинной метки.
Сравнение с версией, которая читала ту же метку, требует той же проводки и питания;
менять соединения вслепую до этого сравнения не нужно.

Проверки: 108 автоматических тестов, включая модель регистров RC522, отвергающую SELECT,
полную цепочку чтения обычного UID и удержание без повторных действий. Проверен запуск
извлечённого установщика. Это программные проверки; аппаратная проверка на Raspberry Pi
пользователя ещё необходима. Обновление не является заявлением об устранении физической причины.

Используется один RC522, SPI0 CE0 / RST BCM25. Python/Tk и библиотеки SPI/GPIO — системные,
в пакет не включены. После установки приложение работает без интернета.
Полная инструкция: Установка-и-RFID.md.
