# Алгебра LAB 0.3.2 — устойчивое чтение одной RFID-метки

Закройте старое приложение. Скачайте .deb, перенесите его на Raspberry Pi.
Откройте терминал в папке с файлом:

    sudo apt install ./algebra-lab_0.3.2_all.deb

Прогресс и назначения меток версий 0.3.0/0.3.1 сохраняются.
Откройте приложение обычным способом из меню, без sudo.

Настройки → RFID-метки → Считать метку.
Уберите метку на 2 секунды, затем поднесите и держите неподвижно около секунды.
После чтения выберите значение и сохраните привязку.
Для повторного срабатывания снова уберите метку минимум на 2 секунды.

Изменения:
- Интервал опроса RC522 увеличен до 350 мс; SPI снижен до 250 кГц.
- UID подтверждается двумя одинаковыми чтениями подряд.
- Временные ошибки обмена не останавливают опрос: поле антенны перезапускается,
  чтение повторяется. Сообщение содержит ErrorReg, если он доступен.
- Ошибка обмена не считается удалением метки и не сбрасывает защиту от повторов.
- Повторное действие разрешается после непрерывного подтверждения отсутствия
  метки в течение 1,2 секунды. Пользователю удобно выдерживать 2 секунды.
- Ошибки доступа к SPI и отсутствующие библиотеки показываются отдельно.

Приложение работает без интернета после установки системных зависимостей.
Для одного RC522 нужны python3-spidev и python3-rpi.gpio. Если они ещё не установлены:

    sudo apt install python3-spidev python3-rpi.gpio

SPI0 CE0 (/dev/spidev0.0), RST BCM25. Дополнительный считыватель не используется.
Сообщение об ошибке обмена само по себе не доказывает наличие нескольких меток.
Питание, проводка, помехи и Low Voltage всё ещё могут вызывать ошибки.

Проверены 82 автоматических теста и работа извлечённого установщика в Linux/X11.
Проверка физического RC522 на Raspberry Pi пользователя ещё необходима.
