# Алгебра LAB 0.3.0 — установщик для Raspberry Pi

Скачайте algebra-lab_0.3.0_all.deb или архив algebra-lab_0.3.0.zip (после скачивания распакуйте).
Перенесите .deb на Raspberry Pi через флешку.
Откройте терминал в папке с файлом и выполните:

    sudo apt install ./algebra-lab_0.3.0_all.deb

После установки откройте «Алгебра LAB» в меню приложений.

Это нативная версия на Python/Tk: 24 задания, мини-уроки, подсказки, сохранение прогресса.
Для занятий можно использовать сенсорные кнопки без RFID-считывателя.

Приложение работает без интернета. Пакет требует Python 3.7+ и python3-tk.
Если эти системные зависимости ещё не установлены, apt потребуется источник пакетов;
сам установщик не включает Python и Tk. Нужна графическая среда рабочего стола.

Это ранее собранная версия 0.3.0; поддержка двух RC522 в неё не добавлена.
Проверки проводились в облачной Linux-среде. На конкретной Raspberry Pi пользователя
приложение ещё не проверено.
