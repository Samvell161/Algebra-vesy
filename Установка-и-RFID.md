# Установка «Алгебра LAB» на Raspberry Pi 3 Model B+

Нативное приложение для графического рабочего стола Raspberry Pi OS. Окно 1024×600, запуск из меню, работа без Chromium, веб-сервера и Интернета. Пакет содержит только Python-код, ярлык, значок и эту инструкцию; Python и Tk используются из системы.

## Совместимость

- Raspberry Pi OS **Buster или новее**, Python **3.7+**, пакет `python3-tk` и графическая сессия X11 либо Wayland с XWayland.
- Пакет `Architecture: all`, без машинного кода ARMv7/ARM64: подходит для ARMv6 Raspberry Pi B+ при наличии перечисленных системных компонентов.
- На конкретной Raspberry Pi 3 Model B+ пользователя ещё не проверен. Версию ОС пользователя пока установить не удалось. На более старых образах с Python 3.5 и ниже пакет не установится.
- 760 МБ свободного места — место на накопителе, а не оперативная память. Размер пакета и полезной нагрузки можно проверить командами ниже. Полный объём установки зависит от уже установленных Python/Tk; менеджер пакетов покажет дополнительные зависимости до установки.

## Установка

Скопируйте файл `algebra-lab_0.4.1_all.deb` на Raspberry Pi. В каталоге с ним:

```bash
cat /etc/os-release
python3 --version
df -h /
sudo apt install --simulate ./algebra-lab_0.4.1_all.deb
sudo apt install ./algebra-lab_0.4.1_all.deb
```

Первая команда apt только показывает предполагаемые изменения. Если требуются Python или Tk, для их загрузки понадобится Интернет. Если оба уже установлены, приложение не требует загрузки браузера или Python-пакетов из pip. Не запускайте графическое приложение через sudo.

После установки: меню приложений → **Образование → Алгебра LAB**. Также можно запустить командой `algebra-lab`. `F11` переключает полный экран, `Esc` возвращает обычное окно. Сенсорная клавиатура для чисел и выражений открывается кнопкой ⌨.

Если ярлык ещё не появился, выйдите из графической сессии и войдите снова. Проверка пакета перед установкой:

```bash
sha256sum -c algebra-lab_0.4.1_all.deb.sha256
dpkg-deb --info algebra-lab_0.4.1_all.deb
```

## Прогресс и обновления

Данные лежат в `~/.local/share/algebra-lab/algebra.sqlite3` (либо в `$XDG_DATA_HOME/algebra-lab`). Обновление пакета сохраняет их. Для резервной копии закройте приложение и скопируйте весь каталог данных. Для переноса прогресса из прежней веб-версии скопируйте её `.local/algebra.sqlite3` в этот каталог, когда оба приложения закрыты. Перенос не происходит автоматически и не перезаписывает существующий профиль.

Одновременно запускается только один экземпляр для одного каталога данных. Незавершённая практика автоматически сохраняется после каждого действия и при закрытии. После запуска нажмите «Продолжить решение». Время вне приложения не прибавляется к попытке. Запуск другого задания заменяет сохранённую практику. Таймерные вызовы и состав чаш не восстанавливаются: физические блоки следует зарегистрировать заново.

## Решение заданий физическими метками — версия 0.4.0

На главной нажмите **Решать физическими метками**. Это включает один RC522 на SPI0 CE0 / RST BCM25 и запоминает аппаратный режим. Учебное задание открывается с отдельным экраном RFID: в нём нет полей для ввода ответа и кнопки ручного применения преобразования. Каждое событие считывателя отправляется в математическую модель задания. Снизу видны роль последней метки, результат действия и состояние считывателя.

### Одна метка: обучение

Выберите **Одна метка · обучение**. Любая уже привязанная метка работает пультом, подтверждающим показанный учебный шаг; её числовое назначение здесь не используется как операнд. Например, приложение предлагает вычесть 3 из обеих частей `x + 3 = 7`; поднесение метки выполняет этот шаг и показывает `x = 4`. Для многошагового примера каждое новое поднесение выполняет только один показанный шаг. После завершения следующее поднесение открывает новое задание, сохраняя экран результата до этого момента.

Это обучение с подсказкой: каждое автоматически выбранное действие учитывается как помощь и снижает звёзды по обычным правилам. Чтение условия и осмысление шага остаются частью занятия; приложение не выдаёт этот сценарий за самостоятельный выбор преобразования. Метки команд «Подсказка», «Отмена», «Следующее» сохраняют свои специальные действия в незавершённом задании. «Следующее» требует завершения текущего задания.

### Набор меток: самостоятельное решение

Выберите **Набор меток · свои действия**. Здесь математическое назначение каждой метки определяет её действие:

- Метки `x`, `−x`, `1`, `−1`, `2`, `−2`, `5` добавляют слагаемые в набираемое выражение. Один UID можно повторно предъявлять после удаления из зоны чтения; это ввод нового слагаемого, а не реестр физического наличия на чаше.
- Метки «Прибавить», «Вычесть», «Умножить», «Разделить» выбирают действие и начинают новый набор операнда. В начале выбран режим вычитания.
- Метка «Применить» выполняет выбранное действие с обеими частями уравнения. До неё на экране меняется набранное выражение, само уравнение сохраняется.
- «Очистить набор» удаляет только ещё не применённые слагаемые. «Отмена» отменяет последний незавершённый шаг решения; «Подсказка» показывает совет с обычным штрафом за помощь.
- «Следующее» открывает следующий пример после завершения текущего. «Шаг с подсказкой» позволяет явно запросить учебное действие и в самостоятельном режиме.

Пример: для `x + 3 = 7` поднесите «Вычесть», затем `2`, затем `1`, затем «Применить». Получится `x = 4`. Можно вместо `2` и `1` трижды поднести одну метку `1`, каждый раз убирая её на две секунды. Для `3x + 2 = 14`: «Вычесть → 2 → Применить», затем «Разделить → 1 → 2 → Применить».

Для полностью физического управления нужны отдельные метки чисел и команд, например `1`, `−1`, `x`, `−x`, четыре действия, «Применить», «Отмена», «Подсказка», «Следующее». С одной меткой доступен описанный выше учебный пульт. Весь набор меток может опрашиваться одним RC522 последовательно; второй считыватель не требуется.

Команды назначаются через **Мои метки → Считать метку → Команды → выбрать роль → Сохранить**. Доступ к этому же окну есть в настройках. Незнакомая метка открывает окно привязки; после сохранения уберите и поднесите её снова. Привязка сама по себе не применяет действие.

При старте приложения на главной известная метка открывает задание или продолжает незавершённое; первое предъявление на главной не выполняет математический шаг, чтобы можно было прочитать условие. Другие диалоги не выполняют действий с уравнением. История применённых физических шагов сохраняется вместе с незавершённой практикой. Ещё не применённый набор операнда при смене режима, новом задании или перезапуске очищается; скрытых отложенных команд нет.

Свободная лаборатория остаётся отдельным реестром физических блоков на чашах: там один UID регистрируется только один раз и команды не добавляются как числа. С неё есть прямая кнопка перехода к решению заданий метками.

## Оборудование

По умолчанию доступны экранные блоки. Для одного RC522 откройте **Настройки → RFID-метки → Считать метку**. Приложение включит считыватель на SPI0 CE0 с RST BCM25 и запомнит режим для следующего запуска из меню. Не нужны команды запуска с `--reader`.

1. Нажмите **Считать метку**, уберите метку от антенны на 2 секунды и поднесите снова.
2. Подержите метку неподвижно около секунды; после двух одинаковых чтений UID зафиксируется. Выберите крупной кнопкой `x`, `1`, `2`, `−x`, `−1`, `−2` (или `5` для прежних блоков).
3. Нажмите **Сохранить привязку** и дождитесь надписи **Сохранено**.
4. Закройте окно и выберите «Решать физическими метками» для учебных заданий. Для свободного реестра блоков откройте лабораторию и выберите чашу. Удержание метки не добавляет блоки повторно. Для следующего срабатывания уберите её минимум на 2 секунды.

Кнопка **Мои метки** показывает сохранённые назначения и позволяет изменить или удалить их. Привязки и учебный прогресс версий 0.3.x сохраняются при обновлении. UID обычных четырёхбайтных меток совместимы с предыдущим SimpleMFRC522. Для изменения значения уже добавленного блока сначала удалите его запись с чаши. Одна физическая метка имеет одно назначение; несколько разных блоков одновременно требуют разных меток.

Если неизвестная метка считана в лаборатории, окно привязки открывается автоматически. Сохранение не добавляет её на чашу: после закрытия окна уберите и поднесите метку снова. Кнопка **UID вручную** служит для проверки без физического считывателя; она не подтверждает работу оборудования.

В версии 0.4.1 исправлен профиль UID-чтения: стандартное усиление RxGain 33 дБ с сохранением резервных битов RFCfgReg, явно заданные режимы ISO14443A, сброс StartSend перед чтением результатов, проверка ErrorReg до трактовки таймера как отсутствия метки. Перед каждой попыткой поле кратко перезапускается, чтобы метка начинала из IDLE, затем идут REQA (7 бит) и ANTICOLLISION. Для обычной четырёхбайтной метки UID читается без SELECT/SAK/HALT — как в UID-only пути SimpleMFRC522 0.0.7. UID + BCC преобразуется в прежнее числовое представление, поэтому привязки сохраняются. Длинные UID по-прежнему читаются с каскадным выбором. Ошибка RF содержит этап, расшифровку ErrorReg и VersionReg, если доступны; например, `REQA: запрос метки: ProtocolErr (ErrorReg=0x01). VersionReg=0x92.`

`0x01` означает ProtocolErr. По одному этому коду нельзя установить, виноваты ли последовательность команд, питание, помехи, тип метки или модуль. Он не доказывает наличие нескольких меток. Если прежняя версия читала ту же метку на той же проводке, следует сравнить программный профиль, а не сразу менять соединения. Обновление 0.4.1 меняет профиль, но до проверки на Raspberry Pi нельзя утверждать, что физическая причина устранена. Закройте старое окно перед установкой; новая версия видна в заголовке окна «Алгебра LAB 0.4.1».

В версии 0.3.2 интервал между попытками — 350 мс, SPI — 250 кГц. UID подтверждается двумя последовательными одинаковыми чтениями. Отсутствие метки должно непрерывно подтверждаться не менее 1,2 секунды; ошибка обмена прерывает это подтверждение и не считается снятием метки. Ошибки RF/проверки UID вызывают повторную попытку с перезапуском поля антенны, сохраняя защиту от повторных действий. Предупреждение показывает ErrorReg, когда он доступен, и исчезает после успешного чтения. Само по себе сообщение об ошибке обмена не доказывает наличие нескольких меток. Отсутствие системных библиотек, отказ доступа или сбой SPI остаются отдельными ошибками подключения. Физическую причину нестабильности нужно проверять на устройстве.

Встроенный драйвер читает только UID; `pip` и пакет `mfrc522` не нужны. На Raspberry Pi включите SPI через `sudo raspi-config` (Interface Options → SPI) и при необходимости установите системные библиотеки:

```bash
sudo apt install python3-spidev python3-rpi.gpio
```

Для загрузки отсутствующих библиотек нужен интернет или заранее подготовленные пакеты. Затем приложение работает офлайн. Для доступа без `sudo` пользователь должен состоять в группах `spi` и `gpio`; проверить можно командой `groups`. Если групп не хватает:

```bash
sudo usermod -aG spi,gpio "$USER"
```

После изменения групп выйдите из системы и войдите снова. Само приложение запускайте от обычного пользователя. Диалог показывает отсутствие библиотек, ошибку доступа, отсутствие ответа RC522 и ошибки чтения прямо на экране. **Считать метку** повторяет подключение; для экранных блоков выберите соответствующую кнопку в настройках.

Схема первого модуля: 3,3 В → физ.1; GND → физ.6; RST → физ.22 (BCM25); MISO → физ.21; MOSI → физ.19; SCK → физ.23; SDA/SS → физ.24. В схеме пользователя это SPI0 CE0, `/dev/spidev0.0`. Приложение не изменяет системную конфигурацию SPI. Второй считыватель и HX711 в этой версии не реализованы. Диагностика на физической Raspberry Pi и проверка качества считывания ещё необходимы; Low Voltage может приводить к нестабильности.

## Удаление

```bash
sudo apt remove algebra-lab
```

Учебные данные в домашнем каталоге сохраняются. Приложение не добавляет автозапуск и не меняет системные сервисы. Для устройства, постоянно используемого как тренажёр, можно добавить его ярлык в автозапуск графической сессии средствами ОС.

## Сборка из исходников

На машине с Python и `dpkg-deb`:

```bash
python3 scripts/build_deb.py
```

Результат — `dist/algebra-lab_0.4.1_all.deb` и файл SHA-256. Доступ к сети и кросс-компилятор не требуются. Тестовая инфраструктура, браузерный интерфейс, Playwright, база пользователя и кэши в пакет не входят.
