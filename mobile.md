# Алгебра LAB: прогресс на Android

## Установка

На Raspberry Pi закройте приложение и установите обновление:

```bash
sudo apt install ./algebra-lab_0.16.0_all.deb
```

На телефоне Android 8.0 или новее откройте algebra-progress_1.2.0.apk. При необходимости разрешите установку приложений для выбранного браузера/файлового менеджера. Приложение называется «Алгебра · Прогресс».

## Первое подключение без QR

1. Подключите телефон и Raspberry Pi к одной обычной Wi-Fi сети.
2. Запустите Алгебра LAB на Raspberry Pi: «Для взрослого → Прогресс на Android · доступ по Wi-Fi».
3. Нажмите «Включить доступ». После запуска службы нажмите «Получить новый код». Шесть цифр действуют пять минут, код используется один раз.
4. На телефоне нажмите «Найти тренажёр», выберите устройство и введите этот код.

Телефон запоминает устройство и доступ, поэтому при следующих запусках повторять код не требуется. Доступ на Pi сохраняется включённым после перезапуска приложения, пока взрослый его не выключит. Можно подключить до восьми телефонов; новое подключение сверх лимита заменяет самое старое. «Отозвать подключения телефонов» сбрасывает выданный доступ. QR-код, камера, аккаунт и интернет не требуются.

## Обновление и экраны

В приложении телефона: список детей → выбранный ребёнок → XP/уровень, успешные попытки по дням, освоенные главы, последние 20 завершённых заданий. Подсказки и время учитываются по завершённым заданиям. Повторное успешное решение считается попыткой на диаграмме; XP, как на тренажёре, определяются лучшими звёздами. Даты диаграммы следуют часам и часовому поясу Raspberry Pi.

Обновление — каждые 25 секунд, пока приложение на телефоне открыто. Есть кнопка «Обновить сейчас». В фоне автообновление останавливается. Сохранённые результаты доступны без связи; показана дата последнего получения. Это не облачный сервис и не фоновые push-уведомления.

На Raspberry Pi приложение должно оставаться запущенным. При переходе к прежнему полному интерфейсу служба доступа запускается там заново с теми же подключёнными телефонами. При закрытии приложения на Pi новые данные временно недоступны. Телефон продолжит показывать сохранённую копию.

## Предложить следующее занятие с телефона (Pi 0.16.0 + Android 1.2.0)

Обновите оба приложения поверх установленных версий. Сохраняются профили, прогресс, метки и подключение телефона. Новых библиотек на Raspberry Pi не требуется.

1. На Pi: «Для взрослого → Прогресс на Android → Разрешить предложения уроков с телефона». Доступ по Wi-Fi также должен быть включён. Изначально право предлагать уроки выключено; чтение прогресса работает независимо от него.
2. На телефоне откройте ребёнка, нажмите «Предложить урок на Pi», выберите доступный уровень и подтвердите отправку. Список содержит 24 урока детского приключения; закрытые уровни показаны серыми. Доступ проверяется повторно на Pi.
3. Текущий пример ребёнок решает как обычно. После его завершения появится «С телефона» с названием урока и кнопками «Открыть / Отклонить». Без согласия ребёнка урок не переключается. Выделение x без проверки ответа ещё не считается завершением.
4. На телефоне карточка «Следующее занятие» показывает результат: ожидает, принято, отклонено, отменено, заменено или истекло. Обновление статуса идёт при обычной синхронизации, максимум через 25 секунд, либо по кнопке обновления.

Один ребёнок — одно ожидающее предложение. Следующее заменяет предыдущее только у этого ребёнка; другие профили не затрагиваются. На Pi должен быть выбран нужный ребёнок. Предложение хранится в SQLite и переживает перезапуск, но действует шесть часов по часам Pi. Во время показа для жюри и в дополнительных взрослых инструментах детское занятие не переключается. При возврате в детский Qt-экран предложение будет проверено снова.

Ожидающий урок можно отменить на телефоне. При потере ответа от Pi подготовленный идентификатор сохраняется на телефоне до подтверждения; «Повторить отправку» повторяет тот же запрос. Принятый, отменённый или заменённый запрос не запускается снова при повторе. Это ручной повтор, фоновой отправки нет. При отключении предложений на Pi ожидающие уроки отменяются. Сброс прогресса ребёнка также отменяет его ожидающий урок.

Предложение — выбор следующего занятия. Оно не добавляет XP, не открывает закрытые уровни, не меняет ответы и не выполняет математические действия вместо ребёнка. «Принято» означает, что ребёнок открыл урок, а завершение отображается в обычной статистике.

## Если поиск не сработал

Проверьте, что доступ включён, устройства в одной сети и используется не изолированная гостевая Wi-Fi сеть. Нажмите «Указать адрес» на телефоне и введите адрес из окна Pi, например 192.168.1.10:8765. Для автоматического поиска используется UDP 8766, для данных TCP 8765. При включённом сетевом фильтре нужны соединения между этими устройствами на указанных портах; выход в интернет и настройка перенаправления портов не нужны.

Если адрес Pi изменился, снова нажмите «Найти тренажёр»: устройство узнаётся по постоянному идентификатору, и сохранённый доступ используется по новому адресу. После отзыва доступа нужно подключиться заново по новому коду.

## Данные и нагрузка

Доступ по сети изначально выключен. После включения передаются только данные прогресса, не назначения меток или настройки GPIO. API не позволяет менять профили, условия заданий и результаты. Если взрослый отдельно разрешил предложения, подключённый телефон может отправить или отменить предложение следующего урока. Чтение не переключает текущий профиль ребёнка. Соединение локальное HTTP с индивидуальным токеном после подключения по коду; используйте доверенную локальную сеть.

На Pi служба использует стандартную библиотеку Python и читает SQLite только по запросам. Диаграммы рисуются на телефоне. Неизменившийся ответ возвращается как HTTP 304, экран не перестраивается без изменений. Дополнительных пакетов Python для доступа к Android не требуется.

Ключи подключения находятся в mobile-access.json в каталоге профиля приложения Pi; этот файл не включается в резервную копию SQLite. После переноса базы на другой тренажёр телефон нужно подключить заново. Телефон хранит только локальную копию данных и ключ доступа в закрытом хранилище приложения; автоматическое облачное резервирование Android отключено.

## Проверки

Проверены HTTP/UDP, код подключения, отзыв доступа, сохранение токена после перезапуска, чтение всех профилей без изменения активного ребёнка, обновление результатов и HTTP 304. Android APK собран, подписан и проверен apksigner; проверки Android-экранов выполнены в Robolectric. Дополнительно проверены авторизация предложений, доступность уровней, изоляция профилей, отмена, истечение срока и повтор после потери ответа; Qt-экран проверен в разрешении 1024×600. Эти автоматические проверки не заменяют запуск обновления на физическом Raspberry Pi и телефоне.
