# Две чаши и две кнопки — версия 0.10.0

Символические весы, без датчиков массы. Метка — величина блока; считыватель определяет сторону, кнопка — действие. Подносим по одной метке, а не складываем несколько на антенне. Первый показ использует фиксированное «Убрать»; со второго урока ребёнок выбирает действие. Для ответа +1/+2 означают число, x подтверждает выбранный экраном ответ. В четвёртой главе x также убирает блоки неизвестного с обеих чаш.

## Настройка приложения

После обновления один считыватель продолжает работать как раньше. В «Для взрослого → Проверка считывателя» включите «Два считывателя», затем «Применить / переподключить». Левая чаша использует SPI0 CE0 / RST BCM25, правая — SPI1 CE0 / RST BCM5. Настройка сохраняется. Можно вернуться к одному модулю, сняв галочку. При отказе одного модуля экран остаётся доступен, исправный модуль продолжает работать. Для отключённой чаши используйте один считыватель с экранным выбором стороны после переключения режима.

Кнопки включаются отдельной галочкой только после проверки соединений. Первая (BCM13) — «Добавить», вторая (BCM26) — «Убрать». Нажмите и отпустите, дождитесь выделения действия на экране, затем поднесите метку к нужной чаше. Пока изменена только одна сторона, смена действия запрещена: повторите операцию на второй чаше или нажмите «Отменить». В квизах, окнах взрослого и при выборе окончательного ответа GPIO-кнопки не выполняют математические действия. Сначала отпустите обе кнопки после включения: удержание при запуске не считается нажатием. Дребезг фильтруется, удержание даёт одно событие, одновременное нажатие не является командой.

## Расположение GPIO и согласованная распиновка

**Положение платы:** USB-разъёмы сверху, GPIO-гребёнка слева. Считаем каждый столбик снизу вверх. Справа — ближе к середине платы, снизу физический контакт 1; слева — ближе к краю, снизу физический контакт 2. Это описание положения, а не новая электрическая нумерация.

| RC522 | Левый: физический контакт / положение | Правый: физический контакт / положение |
|---|---|---|
| 3.3V | 1 / справа 1-й | 17 / справа 9-й |
| RST | 22 / слева 11-й (BCM25) | 29 / справа 15-й (BCM5) |
| GND | 6 / слева 3-й | 9 / справа 5-й |
| MISO | 21 / справа 11-й (BCM9) | 35 / справа 18-й (BCM19) |
| MOSI | 19 / справа 10-й (BCM10) | 38 / слева 19-й (BCM20) |
| SCK | 23 / справа 12-й (BCM11) | 40 / слева 20-й (BCM21) |
| SDA / SS | 24 / слева 12-й (BCM8) | 12 / слева 6-й (BCM18) |
| IRQ | не подключать | не подключать |

RC522 питаются от 3,3 В. SDA здесь — SS/CS режима SPI. Третий модуль не используется. SPI1 занимает GPIO18–21 и конфликтует с I²S/PCM или другим оборудованием на этих линиях, если оно подключено. В согласованной схеме кнопки GPIO13/26 с ними не пересекаются. Таблица не подтверждает фактическую проводку — её нужно сверить на выключенной плате.

## Кнопки: сначала проверить плату

Программа ожидает **обычный сухой контакт**: отпущено — вход подтянут к 3,3 В внутренним резистором; нажато — замкнуто на GND. GPIO13 и GPIO26 всегда настраиваются как входы с PUD_UP. Не подавайте 5 В на GPIO.

| Вход | Физический контакт | Положение при указанной ориентации |
|---|---:|---|
| Первая кнопка, «Добавить» | 33 (BCM13) | справа 17-й снизу |
| Вторая кнопка, «Убрать» | 37 (BCM26) | справа 19-й снизу |
| Земля первой кнопки | 20 (GND) | слева 10-й снизу |
| Земля второй кнопки | 30 (GND) | слева 15-й снизу |

Присланный снимок содержит только текстовую таблицу. По нему невозможно подтвердить внутреннюю схему модуля. Подключение **VCC модуля к GND Raspberry Pi** допустимо лишь если установлено, что VCC и OUT действительно работают как нужная пара контактов механического выключателя и нет активной электроники. Не считайте обозначение VCC универсальным контактом земли.

До подключения к Raspberry Pi полностью отсоедините модуль и проверьте мультиметром сопротивление между предполагаемыми двумя контактами: при отпускании нет замыкания, при нажатии есть замыкание, без постороннего источника напряжения. Проверьте также обратную полярность измерения, чтобы не принять полупроводник за контакт. При неоднозначном результате нужны фото самой платы с двух сторон и маркировка компонента; таблицы из другого чата недостаточно. Подключайте при выключенном питании. До проверки оставьте программную галочку кнопок выключенной — экранные «Добавить / Убрать» доступны.

## SPI1 на конкретной Raspberry Pi OS

Закройте приложение и выполните короткую проверку из установленного пакета:

```bash
algebra-lab --check-hardware
```

Проверка занимает около 8 секунд и не меняет настройки ОС. В начале JSON содержит:

- `config`: найденный `/boot/firmware/config.txt` на новых ОС или `/boot/config.txt` на старых;
- `spi1_overlay`: фактически найденный `spi1-1cs.dtbo`;
- `devices`: существующие `/dev/spidev*`.

Если `spi1_overlay` равен null, не добавляйте неподтверждённый overlay: сначала требуется проверить версию ОС и пакет загрузочных файлов. Если файл найден, откройте **именно путь из поля config**. Пример для новой ОС:

```bash
sudo nano /boot/firmware/config.txt
```

Для старой ОС используйте показанный `/boot/config.txt`. В общей секции `[all]` (в конце файла) добавьте отсутствующие строки, не дублируя существующие настройки:

```ini
[all]
dtparam=spi=on
dtoverlay=spi1-1cs
```

Не добавляйте одновременно другие `spi1-*` overlay и проверьте, нет ли назначения GPIO18–21 под I²S/HAT. Если файл включает другие config через include, проверьте и их. В nano сохранить Ctrl+O, Enter; выйти Ctrl+X.

```bash
sudo reboot
```

После загрузки:

```bash
ls /dev/spidev*
algebra-lab --check-hardware
```

Ожидаются `/dev/spidev0.0` и `/dev/spidev1.0` (дополнительный spidev0.1 допустим). В итоговом состоянии каждой чаши должны быть `connected: true` и VersionReg, обычно 0x91/0x92 (в JSON — 145/146). Поднесение UID выводит событие с `source: left` либо `source: right`. Наличие устройства SPI ещё не подтверждает связь с RC522. Программа повторяет подключение отсутствующего модуля каждые 5 секунд, не блокируя окно.

После проверки проводки кнопок отдельно можно выполнить:

```bash
algebra-lab --check-hardware --check-buttons
```

Ожидаются события `type: button`, `operation: add` для BCM13 и `remove` для BCM26. Диагностика использует ту же блокировку профиля, что приложение; одновременно их не запускайте. Доступ к GPIO/SPI нужен обычному пользователю (стандартные группы gpio/spi Raspberry Pi OS); не запускайте графическое приложение от sudo.

Команда также выводит `vcgencmd get_throttled`, если он доступен. `0x0` — флаги отсутствуют; бит 0 означает текущее пониженное напряжение, бит 16 — зафиксированное после загрузки. Другие биты могут обозначать ограничения частоты/температуры. Ранее наблюдавшееся Low Voltage Warning нельзя считать устранённым без проверки питания.

Антенны включаются по очереди; один UID учитывается отдельно для каждого источника. Ошибка обмена не считается убранной меткой. Для повторного действия на той же чаше уберите метку примерно на две секунды. Даже с поочерёдным опросом нужно проверить расстояние между модулями и устойчивость питания на реальном устройстве.

## История решения

После успеха «Мой путь» показывает исходное условие, пары действий на чашах, равносильные уравнения и подстановку ответа в исходное условие. «Для взрослого → История решений» открывает последние 30 сохранённых путей, включая повторы. Они доступны после перезапуска. Старые результаты без записи шагов сохраняют звёзды, но их путь задним числом не выдумывается. Незавершённая операция только на одной чаше не становится сохранённым шагом. Сброс учебного прогресса удаляет и пути решений; метки остаются.
