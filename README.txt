Алгебра LAB 0.14.0 — карта приключения

Закройте приложение, затем в папке с файлом:
sudo apt install ./algebra-lab_0.14.0_all.deb

Нажмите «Карта»: задания теперь расположены вдоль извилистой тропинки.
Зелёные остановки — пройденные, фиолетовые — доступные, серые — закрытые.
Текущий уровень отмечен золотой обводкой, результаты — звёздами.
Четыре главы переключаются сверху; квиз главы доступен кнопкой внизу.
В открытой главе можно выбирать уровни и повторять пройденные.

Прежний прогресс, профили, метки и правила открытия сохранены.
Карта работает без постоянной анимации, фон кэшируется; новых зависимостей нет.
Скриншот настоящего окна: route-map.png. Подробности: install.md.
