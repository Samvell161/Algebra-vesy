Алгебра LAB 0.19.0 — объёмная мастерская

Фон главного детского экрана заменён на подробную иллюстрацию в стиле качественного 3D-рендера: арочное окно, дерево, латунные детали, фактура стен, мягкое солнечное освещение и тени. Оттенки стойки и контактные тени согласованы с освещением комнаты. За математическими блоками оставлена спокойная светлая стена.

Это подготовленный статичный фон, включённый в приложение, а не живая полигональная сцена с вращением камеры. Анимации весов и блоков остаются действующими анимациями Qt. Изображение создано специально для проекта, сведения — в исходниках qt_ui/assets/README.md.

УСТАНОВКА ОБНОВЛЕНИЯ
Закройте игру. В папке с файлом выполните один раз:
sudo apt install ./algebra-lab_0.19.0_all.deb

После установки запускайте из меню Raspberry Pi → Образование → Алгебра LAB, без терминала. Данные удалять не нужно. Приложение Android 1.2.0 обновлять не требуется.

РАБОТА
Фон хранится локально в установке, интернет не нужен. PNG 2042×770 около 1,9 МБ декодируется один раз и кэшируется. Новых системных зависимостей нет. При отсутствующем или повреждённом файле включается прежняя локальная векторная мастерская. Отключение движения — Для взрослого → Оформление · анимации. Фон остаётся объёмным и при выключенных анимациях.

Размеры окна и кнопок, исходное уравнение, математическая логика, метки, GPIO-кнопки, история и связь с телефоном сохранены.

ПРОВЕРКИ
194 основных теста + 20 Qt-тестов. Проверены загрузка и кэширование иллюстрации из извлечённого DEB, рендеринг 1024×600, все 24 урока, размер сенсорных элементов, RFID во время движения, самостоятельный ответ ребёнка, предложения урока с телефона и возврат из взрослого интерфейса. Отдельно проверен запуск без файла фоновой картинки. Проверки выполнены в облачной среде, а не на физическом Raspberry Pi пользователя. GIF — запись настоящих Qt-виджетов с программными UID-событиями, не замер FPS на устройстве.
