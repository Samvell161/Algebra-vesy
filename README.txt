Алгебра LAB 0.10.0 — Raspberry Pi 3 Model B+

1. Закройте старое окно приложения.
2. Перенесите algebra-lab_0.10.0_all.deb с флешки в папку Raspberry Pi.
3. В терминале этой папки:
sudo apt install ./algebra-lab_0.10.0_all.deb
4. Запуск: меню «Образование → Алгебра LAB» либо команда algebra-lab.

Что нового:
- Два RC522: левый SPI0 CE0 / RST BCM25, правый SPI1 CE0 / RST BCM5.
- Кнопки BCM13 = «Добавить», BCM26 = «Убрать», с защитой от удержания/дребезга.
- Понятные объяснения действий и история решения с проверкой ответа.
- 24 уровня, квизы, XP, метки и прежний прогресс сохранены.

Включение: «Для взрослого → Проверка считывателя».
Для двух чаш сначала проверьте SPI1 по hardware.md. Кнопки включаются отдельно.
Присланная таблица не подтверждает схему кнопки: VCC→GND требует проверки самой платы.
До проверки оставьте GPIO-кнопки выключенными; экранные кнопки работают.

Аппаратная диагностика (закройте окно):
algebra-lab --check-hardware
После проверки кнопок:
algebra-lab --check-hardware --check-buttons

После успеха откройте «Мой путь». Сохранённые решения:
«Для взрослого → История решений» (последние 30 путей, после перезапуска тоже).
Старые результаты остаются; пути прошлых версий задним числом не восстанавливаются.

my-tags.json — резерв назначений ваших трёх меток. Повторный импорт не нужен.
Полные инструкции: install.md и hardware.md.
180 программных проверок и проверка извлечённого установщика пройдены.
Физические RC522 и GPIO в облаке не тестировались — проверка на вашем Pi необходима.
