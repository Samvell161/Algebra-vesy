Алгебра LAB 0.20.0 — новые весы, спокойные материалы и часы

САМИ ВЕСЫ
Основание, фаски, четыре опоры и круглая стойка теперь построены из трёхмерной геометрии с общей камерой. Платформа стоит ровно на поверхности стола. Чаши имеют внешнюю поверхность, внутреннюю выемку и обод; их освещение рассчитывается по нормалям граней. Коромысло — объёмный брус с фасками. Цвета: ореховое дерево, сатиновая латунь, приглушённый зелёный и светлые деревянные блоки.

КНОПКИ И ЧАСЫ
В Qt-интерфейсе добавлены мягкие кэшированные тени кнопок, включая карту и диалоги. На стене — небольшие объёмные часы с движущимися стрелками и маятником. Они обновляют только свою область, не меняют время урока и не влияют на результат ребёнка.

УСТАНОВКА ОБНОВЛЕНИЯ
Закройте игру. Из папки с DEB выполните один раз:
sudo apt install ./algebra-lab_0.20.0_all.deb

После установки запускайте через меню Raspberry Pi → Образование → Алгебра LAB, без терминала. Старую версию и данные удалять не нужно. Android 1.2.0 обновлять не требуется.

НАСТРОЙКИ
Для взрослого → Оформление · анимации.
«Анимации» выключает движение весов и часов целиком.
«Фоновые часы» выключает только часы, сохраняя движение весов.
Настройки сохраняются для ребёнка; скрытое/свёрнутое окно не обновляет часы.

ИНЖЕНЕРНАЯ ЧАСТЬ
Программная 3D-проекция QPainter с фиксированной камерой, без OpenGL-контекста и новых зависимостей. Комната и неподвижные детали кэшируются. Подвижные объёмные части рисуются из кэша, сотни граней не пересчитываются на каждом кадре. Кэш теней кнопок ограничен; отдельный живой фильтр размытия для каждой кнопки не используется. Часы обновляют область около 66×94 px с частотой 10 Гц. Основное движение весов остаётся коротким, с интервалом кадров 33 мс. Математическая логика и RFID не ждут анимаций.

ПРОВЕРКИ
194 основных теста + 22 Qt-теста. Проверены независимое движение/остановка часов, сохранение настройки и профили, размеры кнопок 44×44, все 24 урока, точная математика, обработка RFID во время анимации, готовый DEB, автономная картинка и запасной фон, возврат из взрослого интерфейса и урок с телефона. Проверки выполнены в облачной среде; эта версия ещё не запускалась на физическом Raspberry Pi пользователя. GIF — запись Qt-виджетов с программными UID-событиями, не измерение FPS на Pi.
