Алгебра LAB 0.18.0 — мастерская открытий

Главный экран для Raspberry Pi с touch 1024×600: высокие весы и детская мастерская.

ИЗМЕНЕНИЯ
• Высота области весов — около 377 px вместо 211 px в 0.17.0, коромысло и чаши немного уже; стойка выше, цепи длиннее, блоки крупнее.
• Компактные кнопки: от 44×44 px для касания. Кнопки выбора чаш находятся внизу сцены. Условие остаётся сверху слева.
• Фон с арочным окном, солнцем, холмами, книжными полками, телескопом, колбой, ростком и маленькой ракетой.
• Ясные тёплые цвета вместо широких переливов. Объём создают верхние и боковые грани, ободы, блики и тени.
• Сохранены плавный наклон, появление/удаление блоков и поздравление после верного ответа. Отключение: Для взрослого → Оформление · анимации.

УСТАНОВКА ОБНОВЛЕНИЯ
Закройте игру. В папке с файлом выполните один раз:
sudo apt install ./algebra-lab_0.18.0_all.deb

Потом запускайте через меню Raspberry Pi → Образование → Алгебра LAB, без терминала. Старую версию и данные удалять не нужно. Приложение Android 1.2.0 обновлять не требуется, оно совместимо с этой версией Pi.

Математическая логика, метки, кнопки, прогресс, профили, история и предложения уроков с телефона сохранены. Системные зависимости прежние. Сцена QPainter подходит для Pi 3 B+ и Pi 4 с поддерживаемой ОС/PyQt6; фон кэшируется и не перерисовывается на каждом кадре движения.

ПРОВЕРКИ
194 теста модели, API, данных и других модулей плюс 20 Qt-тестов. Проверены все 24 урока в реальном шрифте и QSS при 1024×600, размер касаний и расположение элементов; математика/RFID во время анимации; готовый DEB, возврат из взрослого интерфейса и предложения с Android. Скачивание установщика проверено по SHA-256.

balance-animation.gif — запись настоящих Qt-виджетов с программными UID-событиями. Это демонстрация, не измерение FPS на Raspberry Pi. Быстродействие этой версии на физических Pi 3/4 ещё не измерено.
