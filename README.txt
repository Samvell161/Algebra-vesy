Алгебра LAB 0.9.0 — обновление для Raspberry Pi

Закройте старое окно приложения. Перенесите algebra-lab_0.9.0_all.deb на Raspberry Pi.
Откройте терминал в папке с файлом:
sudo apt install ./algebra-lab_0.9.0_all.deb

Запуск: меню «Образование → Алгебра LAB» либо команда algebra-lab.
Приложение работает без интернета после установки зависимостей.
Прогресс, настройки и привязки меток сохраняются; повторный импорт не нужен.

В «Карте приключения» теперь 24 уровня в четырёх главах.
Первый уровень — показ. После него можно выбирать любой уровень открытой главы.
Следующая глава открывается после шести решённых задач предыдущей.
После каждой главы доступен квиз из трёх вопросов с объяснениями и XP.
Раздел «Для взрослого» и дополнительные задания сохранены.
Новых библиотек нет; драйвер RC522 и параметры опроса не менялись.

Метки +1/+2 меняют единицы выбранной чаши. В четвёртой главе метка x
позволяет убирать блоки x с обеих сторон. После освобождения x выберите
ответ на экране и проверьте его кнопкой либо меткой x.

my-tags.json — резервный файл трёх ранее назначенных меток.
Подробная инструкция: install.md.
