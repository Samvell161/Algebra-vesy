Алгебра LAB 0.24.0 — анимации карты приключения

На карте при открытии и смене главы плавно появляется тропинка. Над ней плывут облака, у текущего задания развевается флажок и мягко пульсирует ореол. У пройденных остановок при появлении вспыхивают маленькие блики, над лугом летает бабочка. Нажатие доступной остановки даёт короткое кольцо отклика.

Кнопки и подписи видны сразу, их положение и область касания не меняются. Выбор урока не ждёт завершения анимации. Повторное нажатие текущей вкладки сохраняет выделение и не пересоздаёт сцену.

УСТАНОВКА ОБНОВЛЕНИЯ
Закройте игру. Из папки с файлом выполните один раз:
sudo apt install ./algebra-lab_0.24.0_all.deb

Потом запускайте через меню Raspberry Pi → Образование → Алгебра LAB. Старую версию и данные удалять не нужно. Математика, RFID, GPIO-кнопки, прогресс, история, шрифт, весы и Android 1.2.0 сохранены. Android обновлять не требуется.

ДВИЖЕНИЕ
Для взрослого → Оформление · анимации → Анимации.
При выключенном движении карта сразу полностью видна, декорации неподвижны, таймер карты не запускается. При закрытии/скрытии таймер останавливается; смена главы останавливает предыдущую сцену.

Фон, дорога и облака кэшируются. Начальная анимация и отклик касания — интервал 33 мс, фоновое движение — 100 мс с перерисовкой небольших участков. Новых системных зависимостей, сетевых запросов или записей прогресса в фоне нет. Номинальные интервалы не являются замером FPS на физическом устройстве.

ПРОВЕРКИ
26 Qt-тестов: прежние сценарии весов, шрифта, теней, профилей, предложений с телефона и новая карта. Проверены стабильность сенсорных областей, неизменность кэшей при анимации, остановка старой сцены, скрытие/закрытие, отключение движения по настройке настоящего профиля, выбор урока во время появления карты. Из готового DEB проверены настоящая карта и её анимации, а также игровые сценарии и возврат из взрослого интерфейса.

Проверки облачные; эта версия ещё не проверена на физическом Raspberry Pi пользователя. map-animation.gif — запись настоящих Qt-виджетов с демонстрационным прогрессом (первая глава пройдена, вторая открыта), не данные реального ребёнка и не тест производительности Pi.
