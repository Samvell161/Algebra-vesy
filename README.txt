# Спокойные переходы и результат под весами — 0.40.0

Вопрос появляется по сигналу завершения текущего движения: удаляемый кубик исчез, перекладина вернулась к целевому горизонтальному положению и физический таймер завершён. До этого в прежней полосе показано «Весы выравниваются…». После выравнивания вопрос и кнопка проверки проявляются за 180 мс. Высота полосы 44 пикселя; комната, её ракурс и масштаб не меняются.

После успешной проверки сохранён поворот кубика x в проверенное число. Когда его обратная грань развёрнута к зрителю достаточно для чтения (поворот не менее 150°), вместо серых кнопок появляется бирюзовая плашка x = число. Она сохраняется до следующего задания, а «Дальше» остаётся на прежнем месте. При отключённых анимациях переходы мгновенные. Быстрый ответ RFID по-прежнему принимается моделью; его визуальное раскрытие дожидается окончания движения чаш.

Контактные тени внутри чаш чуть заметнее и остаются ограничены их внутренней поверхностью. На полу под чашами появились широкие, очень светлые мягкие тени; их центры и мягкость следуют за положением чаш. Это локальные вычисления существующего шейдера, без новых карт глубины или текстур. Свет из окна, правый светильник и читаемость граней сохранены.

Звезда, XP и имя/звание собраны в один фиксированный блок 192×44. «Исследователь» помещается целиком. Размер карточки условия фиксируется по исходному уравнению, заголовок занимает оставшееся место: изменение сообщения или числа XP не сдвигает соседей. Переключение профилей по нажатию на блок сохранено.

Сообщения о принятых ходах строятся из действия, величины и стороны, а не разбираются из длинного текста: «Убрали 1 справа. Теперь убери 1 слева». Об уравновешенных чашах сообщается после завершения движения. Правила заданий, физические кнопки, RFID, прогресс и Android не менялись.

Новых зависимостей нет. Плавное появление — маленькая рисуемая шторка над одной полосой интерфейса, без размытия всей сцены. На подключённой Pi 4 проверка недоступна; FPS устройства не измерен.

```bash
sudo apt install ./algebra-lab_0.40.0_all.deb
```


УСТАНОВКА
Закройте игру. Выполните команду выше из папки со скачанным DEB.
Запуск: меню Raspberry Pi → Образование → Алгебра LAB.
Метки, сохранения, профили, история, XP, уровни и Android сохраняются. Новых зависимостей нет. Пакет около 6,2 МБ; содержимое около 7,8 МБ без системных библиотек.

ПРОВЕРКИ
285 разных тестов: 234 логики/данных/геометрии/прежнего интерфейса, 30 совместимого Qt-вида, 21 настоящего GL-режима. Проверены вопрос после окончания движения, исчезновение последней единицы, горизонтальная перекладина, плашка результата при читаемой грани, ответы 2 и 3, неверный ответ, отключение анимаций, быстрый ответ RFID, возврат к новому заданию, неизменность верхней панели при больших XP и длинном сообщении. Итоговый DEB распакован и проверен: 71 файл по MD5, 2871 запись PyOpenGL, штатные функциональные сценарии, диагностика и запуск без NumPy.

ВИДЕО
balance-actions-30fps.mp4 — 22 секунды, 660 кадров при 30 FPS. Сценарий x + 2 = 4 сохранён. Около 18,2 с появляется вопрос после выравнивания; около 20,6 с — плашка x = 2 при читаемой грани кубика. Во всех кадрах область комнаты 1004×386 и одна матрица камеры; геометрия верхней панели и полное слово «Исследователь» проверены.
settling.png — кубик ещё уходит, вопрос скрыт; answer-entry.png — вопрос после выравнивания; result-badge.png — первое появление плашки; revealed.png — конечный результат. comparison.md показывает эти этапы. real-3d.gif / balance-actions-30fps.gif — та же демонстрация.
Кадры получены из установленного приложения с виртуальным шагом 1/30 с; короткое проявление полосы тоже записано покадрово. Это не аппаратный замер FPS Raspberry Pi. Физическая Pi 4 и настоящие считыватели здесь недоступны; события RFID/кнопок проверены симулятором.
