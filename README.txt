Алгебра LAB 0.12.0

Закройте приложение. В папке с установщиком:
sudo apt install ./algebra-lab_0.12.0_all.deb

В Qt-меню «Для взрослого»: проверка меток и кнопок, резервное копирование,
восстановление базы, экспорт журнала. Возле чаш показано состояние считывателей.
Незавершённый ход можно продолжить или отменить после перезапуска.

Настройки и дополнительные режимы прежнего интерфейса пока доступны
отдельной кнопкой: полный перенос всех экранов в Qt ещё не завершён.
Автоматическая копия перед обновлением пока не добавлена; копия делается вручную.
Новых зависимостей относительно 0.11.2 нет. Метки и прогресс сохраняются.
Подробности: install.md.

Проверки: 187 тестов (Qt-тесты выполнены отдельно); дополнительно проверен
извлечённый установщик, возврат из полного интерфейса и сценарии резервных копий.
