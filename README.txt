Алгебра LAB 0.26.0 — физика, разные наклоны, новый фон и читаемый шрифт

ЧТО ИЗМЕНИЛОСЬ
Величина наклона зависит от разницы чаш: ½ → 1°, 1 → 1,8°, 2 → 3°, 4 → 4,5°, 8 → 6°. Большая разница плавно приближает наклон к 9°. Направление меняется зеркально. Для оценки чаш используется решение исходного задания; правила игры и проверки ответа не изменились.

Коромысло движется с инерцией и затуханием, чуть медленнее при большем числе блоков. Ускорение чаш влияет на движение кубиков. Быстро опускающаяся чаша может ненадолго потерять контакт с блоком; он приземляется с небольшим ограниченным отскоком и передаёт слабый импульс коромыслу. Контакты с дном, укладка пятого блока и запрет прохода через соседей сохранены. Физика использует короткие ограниченные подшаги и завершается через 1,2 с. Зона отрисовки рассчитана на сильный наклон.

На фоне появились деревянные счёты и полка с совёнком и бумажным корабликом. Это часть статичной локальной иллюстрации, без нового таймера или сетевого сервиса. Фон расположен за интерактивными весами.

Для текста выбран читаемый Nunito (производное имя Algebra Rounded): обычный текст и жирные заголовки/кнопки. Составные формулы на широких блоках больше не уменьшаются заранее. Шрифты с кириллицей и знаками включены в пакет вместе с лицензией OFL.

УСТАНОВКА ОБНОВЛЕНИЯ
Закройте игру. Из папки с файлом выполните один раз:
sudo apt install ./algebra-lab_0.26.0_all.deb

Затем запускайте через меню Raspberry Pi → Образование → Алгебра LAB.
Старую версию и данные удалять не нужно. Метки, GPIO-кнопки, профили, уровни, XP, история и Android 1.2.0 сохранены. Android обновлять не требуется.

Новых системных зависимостей относительно 0.25.0 нет. Если предыдущая версия уже установлена с её библиотеками, обновление с флешки не требует интернета. При первой установке нужны системные Qt-зависимости, перечисленные в DEB. Пакет около 4,3 МБ, установленное содержимое около 5,24 МБ без системных библиотек.

Анимации можно выключить: Для взрослого → Оформление · анимации.
Тогда новое состояние и рассчитанный угол показываются сразу. Часы отключаются отдельно. Кэши деталей, шрифтов и фона сохранены, постоянного физического расчёта в покое нет.

ПРОВЕРКИ
204 проверки логики, физики и прежнего интерфейса + 29 Qt-проверок = 233 разных теста. В частности: монотонность и знак угла, дроби, огромные значения без переполнения, инерция, устойчивость, ускорение чаш, контакт/приземление, отсутствие ударов в покое, крайние наклоны и RFID-действия на 1, 2 и x. Из итогового DEB проверены настоящие шрифты, 1024×600, области касания, исходное условие, история, резервная отрисовка, анимации карты, предложения Android и возврат из прежнего взрослого интерфейса. Пять отдельных запусков полноэкранного приложения штатно закрылись во время работы физики.

Проверки облачные; эта версия ещё не проверена и не измерялась на физической Raspberry Pi пользователя. Это символические учебные весы с программной 3D-проекцией и визуальной пружинной реакцией. Датчиков настоящей массы нет.
