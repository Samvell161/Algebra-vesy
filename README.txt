Алгебра LAB 0.30.0 — настоящая 3D-мастерская

Это новая основная сцена OpenGL: весы, комната и предметы на фоне построены из пространственных треугольных моделей. Перспективная камера, аппаратная проверка глубины, освещение по нормалям, падающие тени и GPU-сглаживание. Заранее отрисованная картинка комнаты в новой сцене не используется.

ЧТО МОЖНО УВИДЕТЬ
Объёмные чаши, звенья цепей, стойка, основание и кубики. В комнате — арочное окно, пейзаж, деревья, облака, полки, книги, ракета, телескоп, счёты, карта-барельеф, планетный барельеф, растение, совёнок и часы. Облака медленно перемещаются, стрелки и маятник часов движутся как настоящие геометрические детали. Буквы смешиваются с материалом передних граней кубиков, а не рисуются поверх сцены отдельными плоскостями.

Кнопка «Ракурс» показывает комнату прямо, справа и слева. Можно провести пальцем по комнате. Предметы имеют глубину и меняют взаимное положение на экране при повороте камеры. Камера не меняет уравнение или прогресс.

Кубики учитывают глубину чаши и четыре нижних угла, движение по трём осям, крен и укладку. Сохранены инерция весов и плавная зависимость наклона от разницы: 1 → 1,8°, 2 → 3°, 8 → 6°. Математическая проверка остаётся отдельной от визуальной физики. Это символические алгебраические весы; датчиков настоящей массы нет.

УСТАНОВКА
Закройте игру. Из папки с файлом выполните один раз:
sudo apt install ./algebra-lab_0.30.0_all.deb

Потом запускайте через меню Raspberry Pi → Образование → Алгебра LAB.
Старую версию и данные удалять не нужно. Назначения меток, GPIO-кнопки, профили, уровни, XP, история и Android 1.2.0 сохранены. Android обновлять не требуется.

Библиотека PyOpenGL включена в DEB, отдельно pip и NumPy не нужны. Неиспользуемые Windows DLL в установленном Python-архиве отсутствуют. Системные GL/EGL-библиотеки объявлены зависимостями и обычно уже установлены вместе с PyQt6. Пакет около 6,2 МБ, установленное содержимое около 7,7 МБ без системных библиотек. Интернет при запуске не требуется.

ГРАФИКА
Нужен работающий драйвер OpenGL 2.1 или OpenGL ES 2.0. На ARM запрашивается ES 2.0, чтобы не требовать от Raspberry Pi 3 API ES 3. Сцена встроена через нативное GL-окно; сенсорные кнопки находятся под ним и остаются доступными.

Сведения о драйвере: Для взрослого → Оформление · анимации.
Проверка без открытия учебной базы:
algebra-lab --check-3d
Ожидается "ok": true и название драйвера.

При выключении анимаций состояние показывается сразу, а камера переключается без перехода. Фоновое движение можно выключить отдельно. Совместимый прежний вид доступен явно:
algebra-lab --software-view
Он не подменяет основной 3D-режим автоматически. Если контекст создать не удалось, приложение сообщает об ошибке и сохраняет доступ к управлению.

ПРОВЕРКИ
245 разных тестов: 210 проверок логики, данных, физики и прежнего интерфейса; 29 проверок совместимого Qt-вида; 6 проверок настоящего GL-режима. GL-набор выполнен с контекстами, ограниченными OpenGL 2.1 и OpenGL ES 2.0, включая выход отдельными процессами во время работы физики. Проверены нормали, ориентация треугольников, XYZ-контакты, перспектива, параллакс, тени, кэши, работа без NumPy, ошибка шейдера и доступность кнопок.

Из итогового DEB проверены полная 3D-сцена, исходное условие, RFID-пара действий, укладка пятого кубика, явный ответ ребёнка, история, возврат из раздела взрослого, предложения Android и отключение движения. Старая иллюстрация комнаты удаляется только из временно распакованного пакета: новая сцена продолжает работать. Проверены все 63 установленных файла по md5 и неизменность Python-кода PyOpenGL относительно официального источника. Диагностика --check-3d не создаёт профиль и не открывает оборудование.

Проверки выполнялись на Mesa в облачной среде. На физической Raspberry Pi пользователя эта версия ещё не проверена; реальные FPS и драйвер следует проверить на устройстве. Номинальные интервалы обновления не являются замером производительности Pi.
