Алгебра LAB 0.15.0 + Android «Алгебра · Прогресс» 1.0.0

Файлы:
- algebra-lab_0.15.0_all.deb — обновление Raspberry Pi;
- algebra-progress_1.0.0.apk — Android 8.0 или новее;
- mobile.md — полная инструкция;
- algebra-lab_0.15.0_source.zip — исходники и сборочные скрипты.

1. Закройте игру и установите на Raspberry Pi:
sudo apt install ./algebra-lab_0.15.0_all.deb
2. Откройте APK на телефоне и установите его.
3. Подключите оба устройства к одной Wi-Fi сети.
4. На Pi: Для взрослого → Прогресс на Android → Включить доступ → Получить новый код.
5. На телефоне: Найти тренажёр → выбрать устройство → ввести шесть цифр.

Код требуется один раз. Телефон запоминает устройство. Открытое Android-приложение
обновляет результаты раз в 25 секунд; есть ручное обновление. Без связи доступны
сохранённые результаты и дата последнего получения. На Pi игра должна оставаться запущенной.
Если поиск блокируется сетью, предусмотрен ручной ввод адреса с экрана Pi.
QR, камера, облачный аккаунт и интернет не нужны.

Профили и назначения меток на Pi сохраняются. Новых зависимостей у .deb нет.
APK подписан; API и экраны проверены программно. Реальная связь с вашим телефоном
в вашей Wi-Fi сети ещё не проверялась. Подробности и ограничения — mobile.md.
