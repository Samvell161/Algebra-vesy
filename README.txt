Алгебра LAB 0.16.0 + Android 1.2.0

Новое: взрослый выбирает следующий доступный урок на телефоне. Raspberry Pi ждёт завершения текущего примера и согласия ребёнка. Можно отменить предложение, посмотреть статус, повторить неподтверждённую отправку без дубликата. У каждого ребёнка своя очередь из одного ожидающего урока; срок — 6 часов. Интернет не требуется.

УСТАНОВКА
1. Закройте приложение на Raspberry Pi. Откройте терминал в папке с DEB:
   sudo apt install ./algebra-lab_0.16.0_all.deb
2. На телефоне откройте algebra-progress_1.2.0.apk и установите поверх прежней версии. Старое приложение не удаляйте: профили и подключение сохраняются.
3. Запустите Pi: Для взрослого → Прогресс на Android → Разрешить предложения уроков с телефона. Доступ по Wi-Fi должен быть включён; оба устройства — в одной сети.
4. На телефоне откройте ребёнка → Предложить урок на Pi → выберите урок → Отправить.
5. Ребёнок завершает текущий пример и нажимает «Открыть» или «Отклонить» в предложении на Pi.

Файлы:
algebra-lab_0.16.0_all.deb — Raspberry Pi (штатные PyQt6/QtAwesome уже нужны предыдущей версии).
algebra-progress_1.2.0.apk — Android 8.0+, подпись совпадает с предыдущей версией.
algebra-lab_0.16.0_source.zip — исходники обоих приложений, тесты, инструкции.
mobile.md — подробное подключение, поведение очереди, диагностика Wi-Fi.

ПРОВЕРКИ
207 Python-тестов: 194 в основном запуске и 13 отдельно с Qt. Пять Android-тестов Robolectric. Проверены сборка и подпись APK, совпадение сертификата с 1.1.0, извлечённый DEB, детский экран 1024×600, возврат из взрослого интерфейса, разрешения, отмена, изоляция профилей, перезапуск и повторы отправки. Проверки выполнены в облачной среде; эта версия ещё не запускалась на физических устройствах пользователя.
