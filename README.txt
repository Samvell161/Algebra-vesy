# Игровая комната с длинными маршрутами — 0.38.0

За окном второго/третьего этажа — только небо, солнце и три слоя движущихся облаков; горы и деревья удалены. Горшок и глобус стоят на деревянном столике с ножками, ящиком и нижней полкой. На стене над стеллажом — стилизованная карта мира. На полу слева и справа — группы повёрнутых деревянных кубиков и колечки.

Робот проходит 11,6 единицы сцены через весь передний план, плавно разгоняется, останавливается, разворачивается и идёт обратно. Цикл — 18,4 секунды. Ноги шагают попеременно, руки качаются вокруг плечевых шарниров. Две машинки с вращающимися колёсами объезжают основание по широкому овальному маршруту. Маршруты разнесены по глубине: машинки не заезжают в основание и не пересекают полосу робота. Голова совы поворачивается вокруг вертикальной оси на ±30° вместе с глазами, оправой и клювом; моргание сохранено.

Правый светильник и его настоящий источник перенаправлены вниз на правую часть комнаты. Световое пятно теплее и заметнее, переключатель лампы сохранён. Под машинками и роботом мягкие контактные тени следуют за их координатами. Они рассчитываются в существующем шейдере пола, без новых текстур или проходов карты глубины. Геометрия и карты теней кэшируются как прежде. Ракурс, чаши, символы и учебная логика сохранены.

«Для взрослого → Оформление · анимации → Живой фон» останавливает весь декор, сохраняя движения чаш. Общее отключение анимаций останавливает всё. Настройки качества прежние, новых зависимостей нет. Прямого доступа к физической Pi 4 здесь нет: FPS на устройстве не измерен.

```bash
sudo apt install ./algebra-lab_0.38.0_all.deb
```


УСТАНОВКА И ДАННЫЕ
Закройте игру перед обновлением. Команду выше выполните в папке со скачанным файлом.
Запуск: меню Raspberry Pi → Образование → Алгебра LAB.
Метки, сохранения, история, XP, уровни и Android остаются прежними.
Приложение работает без интернета. Пакет около 6,2 МБ; содержимое около 7,7 МБ без системных библиотек. Новых зависимостей нет; PyOpenGL уже включён в DEB.

ПРОВЕРКИ
275 разных тестов: 230 логики/данных/геометрии/прежнего интерфейса, 29 совместимого Qt-вида, 16 настоящего GL-режима. GL проверен на Mesa OpenGL 2.1 и OpenGL ES 2.0. Проверены движение по маршрутам, развороты, размещение в кадре, отсутствие пересечений с основанием, читаемость кубиков при движущемся декоре и крайних наклонах, отключение движения и сохранение настроек. Проверен итоговый распакованный DEB: 69 файлов по MD5, 2871 запись PyOpenGL, RFID, явный ответ ребёнка, история, возврат из раздела взрослого, Android-предложение и выход во время анимации.
