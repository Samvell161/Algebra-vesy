Алгебра LAB 0.17.0 — объёмные весы и короткие анимации

НОВОЕ
• Чаши с внутренней поверхностью, цепи из звеньев, объёмные стойка и коромысло, блоки с тремя видимыми гранями.
• Плавный наклон и возврат к равновесию, появление и удаление блоков, короткое поздравление после верного ответа.
• Объёмные состояния кнопок и узлы карты. Отключение движения: Для взрослого → Оформление · анимации.

Это 3D-стиль, отрисованный через QPainter, без вращаемой полигональной сцены и 3D-движка. На Raspberry Pi 3 B+ не нужны новые зависимости. Движение длится меньше секунды и не блокирует управление; в покое таймер анимации выключен. Фон и спрайты блоков кэшируются. Данные, RFID, кнопки, исходное уравнение, уровни и логика решения сохранены.

УСТАНОВКА (ОДИН РАЗ ДЛЯ ОБНОВЛЕНИЯ)
Закройте игру. В папке с DEB выполните:
sudo apt install ./algebra-lab_0.17.0_all.deb

После установки запускайте значком: меню Raspberry Pi → Образование → Алгебра LAB. Терминал каждый раз не нужен. Старые данные удалять не нужно. Android 1.2.0 остаётся совместимым, обновлять приложение телефона для этой версии Pi не требуется.

balance-animation.gif — запись настоящего Qt-окна 1024×600 с программными UID-событиями: убрать +2 слева, повторить справа, ребёнок подтверждает x=2. Это демонстрационная запись, не замер частоты кадров на Raspberry Pi.

ПРОВЕРКИ
194 теста модели, хранения, API и прочих модулей плюс 18 Qt-тестов: остановка анимации, повторные события во время движения, отключение/сохранение настройки, геометрия цепей, отсутствие изменений в исходном условии, RFID и профильные сценарии. Проверены извлечённый DEB, экран 1024×600, самостоятельный ответ ребёнка, предложения урока с Android и возврат из взрослого интерфейса. Облачные проверки не заменяют проверку производительности на физическом устройстве пользователя.
