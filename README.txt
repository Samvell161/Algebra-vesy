Алгебра LAB 0.13.0 — профили детей и показ для жюри

Закройте приложение. В папке с файлом:
sudo apt install ./algebra-lab_0.13.0_all.deb

Профили: нажмите имя в верхней панели либо «Для взрослого → Кто играет?».
Каждый ребёнок получает отдельные уровни, XP, историю и незавершённое задание.
Назначения меток общие. Прежние результаты сохраняются в первом профиле.
Резервная копия содержит все профили.

Показ: «Для взрослого → Показ для жюри · 2–3 минуты».
Прочитайте памятку и закройте её, чтобы действовать метками на весах.
Решается x + 2 = 4: изменить одну чашу, повторить на другой, выбрать ответ 2,
показать «Мой путь». Подходит метка +1 либо +2. Прогресс ребёнка не меняется.
Кнопка «Завершить показ» возвращает к прежнему примеру ребёнка.
Печатный сценарий — jury-demo.md. Полная инструкция — install.md.

Проверены миграция старой базы, независимость профилей, демонстрация без
начисления настоящих XP, резервное копирование и извлечённый установщик.
Новых внешних зависимостей нет.
