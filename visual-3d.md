# Объёмное оформление 0.17.0

Обновление предназначено для Raspberry Pi 3 Model B+ и экрана 1024×600. Android 1.2.0 остаётся совместимым; обновлять телефон для оформления весов не требуется.

## Что видно на экране

Чаши с внутренней поверхностью, ободом и бликами; цепи из чередующихся звеньев; стойка с несколькими гранями, основание с толщиной; золотое коромысло и металлические шарниры. У блоков видны лицевая, боковая и верхняя грани. Перспективный пол и контактные тени помогают читать расположение деталей. Кнопки получили объёмные границы и состояния нажатия, точки карты — освещение.

Это программная отрисовка в 3D-стиле через QPainter: перспектива, грани, свет и тень. Не полигональная сцена с вращаемой камерой. OpenGL, Qt3D, игровой движок и новые системные зависимости не нужны.

## Анимации и управление

- Изменение одной чаши плавно наклоняет коромысло; цепи остаются закреплёнными в его концах. Повтор действия на второй чаше плавно возвращает равновесие.
- Добавленные блоки коротко опускаются в чашу, удалённые приподнимаются и исчезают.
- После подтверждённого верного ответа появляется короткая россыпь звёзд. Это оформление; ответ по-прежнему должен дать ребёнок.
- Обычный переход занимает 460 мс, поздравление — 680 мс. Новое событие сразу задаёт новую цель движения, без очереди визуальных команд.
- «Для взрослого → Оформление · анимации → Анимации: включены / выключены». Настройка сохраняется для ребёнка и совместима с прежним параметром motion. Объёмное оформление остаётся при выключенном движении. Показ для жюри также учитывает отключение движения.

Модель и исходное условие меняются независимо от кадров отрисовки. Считыватели и сенсорные кнопки работают во время анимации; математические действия не ждут её окончания. Исходное уравнение остаётся сверху слева. Метки, прогресс, уровни, история и предложения уроков с Android сохранены.

## Расход ресурсов

Один таймер с интервалом 33 мс активен только во время действия. Нет постоянного вращения или фоновых частиц. После окончания движения или скрытия весов таймер останавливается. Фон, перспектива и неподвижная стойка хранятся в кэше; блоки — в ограниченном кэше до 64 спрайтов. При неизменном состоянии повторно используется готовый кадр. Не используются эффекты размытия или теней для каждого виджета. Дроби и выражения остаются текстом, без Matplotlib или генерации формул на каждый кадр.

Длительности и остановка анимаций, перенацеливание при быстрых событиях, закрепление цепей и работа UI проверены автоматически. Это не замер частоты кадров на физическом Raspberry Pi: быстродействие зависит от графической сессии и устройства. При необходимости движение отключается одной кнопкой.

## Установка

Закройте игру и установите обновление из папки с файлом:

```bash
sudo apt install ./algebra-lab_0.17.0_all.deb
```

Пакет обновляет прежнюю установку; данные удалять не нужно. Для последующих запусков откройте меню Raspberry Pi → Образование → Алгебра LAB. Терминал нужен только для установки обновления, не для каждого занятия.
